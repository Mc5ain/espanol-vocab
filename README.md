# Español 专业西语词汇 · 网页版

面向西班牙语专业学生的离线优先网页应用，包含 1,657 个 A1–C1 词条且全部配有双语例句，支持 DELE B1/B2/C1 分级学习、SM-2 间隔复习、双向选择题和动词变位训练。

## 功能

- 首页学习进度、待复习量和分类掌握度
- 首页展示现在、今天稍后、明天和未来 7 天的复习安排
- 首页展示最近 7 天学习量，并自动归档最近 90 天的每日活动
- 每日学习目标可选 10、20 或 30 项，学习队列和首页进度会同步调整
- 达到每日目标后首页会显示完成状态，并保留继续巩固入口
- DELE B1、B2、C1 目标级别切换，默认 B2
- 环境、健康、工作经济、教育科技、住房城市、媒体社会、艺术文化、学术调查主题
- 翻卡学习，翻面后用“还不熟/记住了”判断，SM-2 自动安排复习
- 翻卡、小测和变位训练的队列、当前位置、已选答案及得分会保存在当前标签页，刷新后可继续原进度
- 左右滑动区分“还不熟/记住了”，并支持撤销上一张
- 待复习专项队列和键盘快捷键
- 小测、变位和翻卡共用学习记录、连续天数与每日进度
- 桌面端小测和变位支持 A–D 选项快捷键及 Enter 继续
- 小测已有进度时切换模式会先确认，避免误操作清空当前题目
- 自动汇总未解决的错词与薄弱变位，答对一次消掉一次待巩固记录，归零后自动移出错题本
- 支持错词专项重练，完成后可直接重练同一类题目
- 翻卡、小测和变位结果页可直接进入错题本或薄弱变位列表
- 西班牙语浏览器语音朗读
- 单词和完整例句均可朗读，学习卡片、小测反馈与词库详情都提供独立发音入口
- 小测讲解显示词性、阴阳性和常见搭配，并可直接收藏重点词
- 朗读支持西班牙、拉丁美洲两种口音偏好和慢速、正常、快速三档语速
- 西语词目、例句和选项标记语言属性，读屏器可使用正确发音规则
- 名词阴阳性、语域和固定搭配展示
- 多词固定表达自动标注为短语，单词词性缺少可靠依据时不做猜测
- 西班牙语与中文双向四选一，以及看中文写西语的拼写、听发音写西语的听写训练
- 拼写训练接受省略重音符号的答案，并单独提示重音差异
- 三种小测遇到不会的题都可直接显示答案，并自动记入错题复习
- 中文释义已去除重复和明显 OCR 错配，中文→西语选项会排除同义干扰项
- 现在时、简单过去时、现在虚拟式变位训练
- 变位题可朗读动词原形，答后可朗读正确变位形式
- 可随时打开 24 个动词的完整变位表，按动词和时态浏览并逐项朗读
- 1,657 个词条的搜索、分类和 CEFR 等级筛选
- 搜索支持西语、中文、词性、语域、分类、搭配和例句
- 词库详情显示词条的下次复习时间
- 支持收藏重点词、只看收藏，并在学习记录导出和导入时保留收藏
- 可从词库直接生成仅含当前级别收藏词的翻卡学习队列
- 词库按 60 条分批显示，避免一次渲染上千个词条
- 其中 1,304 个词目依据用户提供的《DELE考试精选词汇B2》整理
- 搜索可忽略西班牙语重音符号
- 学习记录持久保存在浏览器 `localStorage`
- 学习记录在内存中安全复用，并自动清理无效词条、异常统计和超量历史数据
- 学习记录支持 JSON 完整备份，包含收藏、历史、每日目标、小测模式和朗读设置
- PWA 离线缓存，可添加到手机主屏幕
- 联网时优先获取最新版本，断网后自动回退到离线缓存
- 电脑端使用侧边导航、双栏学习卡片和键盘快捷键，手机端保持单栏触控布局
- 手机端可从“数据与许可”中使用安装入口
- 各页面支持锚点直达与浏览器返回手势，刷新后保留当前页面

## 本地运行

```bash
npm run build
npm test
npm run serve
```

打开 `http://localhost:4173/`。

`npm test` 会检查词库数量、重复词条、缺失字段、例句翻译配对和常见 OCR 断词问题。

## 数据构建

词条源文件位于 `src/data/`：

- `words.js`：A1–A2 基础词
- `professional.js`：B1–C1 专业词
- `conjugations.js`：24 个高频规则与不规则动词的三种时态变位

运行下面命令会生成浏览器使用的 `assets/data.js`：

```bash
npm run build
```

## 部署

本项目是纯静态站点，可直接部署到 GitHub Pages。仓库默认分支为 `main`，Pages 使用根目录。
